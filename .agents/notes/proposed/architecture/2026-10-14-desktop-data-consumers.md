## Abstract

This ledger maps business consumers, private adapters and injected callbacks to proposed domain Services so shared ownership does not leave Repo/Doc/transport escapes. Static candidates pin remote main and are supplemented with persistent input, presence, prefetch and thin command entries. All destinations remain proposed; no production behavior/lint gate has passed, and undecided rows block domain completion.

## Contract constraints for this revision

Choose among four phase-one policies from real callers: wait-for-route, bounded-confirmation, require-route and retain-until-ack; see the [sync register](2026-10-14-desktop-data-process.md#syncauthority-caller-register). Session SyncTarget is session-control only. Backend/write commands retain Roost history flush/owner receipts independently of control ACK. DirectoryStatus.cloud and SyncAuthority(workspace-meta) share one state source.

Phase-two MachineRpc server network ingress belongs to host, execution handlers to daemon; gate cutover on host-failure timeout/unknown and recovery queries. Daemon loss retires machine/active publication leases within a bound while daemon still owns actual execution release. Static boundaries ship as pnpm check lint, moving corresponding source constraints out of Vitest. This revision defines gates without implementing lint or migrating rows.

This revision compares main 7541fbf76d154e3a98987e646c6aa932baebacd5 with this ledger's df5b5a0: audited sync/RPC/presence source is unchanged, while new settings changes have not received a complete rescan. Refresh inventory/allowlists before each implementation slice; table line numbers still belong to the original pinned SHA.
